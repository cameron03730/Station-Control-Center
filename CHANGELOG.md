versioning follows [Semantic Versioning](https://semver.org/) — `MAJOR.MINOR.PATCH`.

- **MAJOR** — breaking change to a view contract, script signature, or named-query dependency.
- **MINOR** — new tab/feature or capability, backward compatible.

## [1.1.0] — 2026-07-20
Interactive Help, script-library cleanup, and release/packaging tooling.

### Added
- **Interactive Help & Guide** — the in-app Help popup (`scc-help`) is now an accordion: each
  tab's section has a **More info** toggle that expands a step-by-step walkthrough (numbered
  steps + "watch out" notes). Collapsed by default. Generated by `files/_gen_help.py`.
- **Release & packaging tooling** — the "Package SCC Views" GitHub Action,
  `scripts/scc-update-dev.ps1` (tag + ingest + rebuild + push, gated on real view-source
  changes), `files/_ingest_zip.py` (export zip → `.txt`), this `CHANGELOG.md`, and
  `docs/RELEASE_NOTES_TEMPLATE.md`.

### Changed
- **StationControl.SCC** script library rewritten to plant house style — a full docstring on
  every function (Called from / Example / What it does / Args / Returns), descriptive variable
  names, and de-duplicated logic. Removed the redundant `getTagFolder` and
  `stationComponentIdTagPath` wrappers (callers use `StationControl.DynamicView.getTagFolder`
  directly) and the non-house `.quality.isGood()` tag-read ceremony. No behavior, signature, or
  named-query changes; public function names and `runAction` dispatch keys unchanged.
- **scc-page header** simplified — removed the "authorized manual interventions" subtitle,
  shortened the badge to "JEFFERSON CITY", and removed the version pill.
- **scc-help** — removed the obsolete "Boom Associations" section (that editor was retired).
- Text sources and the import bundle normalized to LF line endings (`.gitattributes`).

### Fixed
- `scripts/scc-update-dev.ps1` — ASCII-only for Windows PowerShell 5.1, exit-code-based change
  detection, and no `.Trim()` on a null `git status --porcelain` (clean-tree crash).

## [1.0.0] — 2026-07-16
First production release of the Station Control Center inside the FactoryControl project.

### Added
- **scc-page** tab shell — button-strip navigation over a single swapped `ia.display.view`
  (no `ia.container.tab`), gated on Engineering / Supervisor / Scheduler roles.
- **Station ComponentID Rectify** — read/verify/commit a station's `fromIGN/componentID`
  with WIP + AMR-bound boundary checks before write.
- **AMR ComponentID Rectify** — read/commit an AMR's `machineInfo/componentID`.
- **Run Schedule Refresh** — fires `getOrder` + `updateRunSchedules` on the owning backend.
- **Manual Assembly Schedule** — serial validation + `createAssemblyOrder` on BE2.
- **Work Order Reconciliation** — component/serial schedule lookup and mark-complete (WG + NWG).
- **StationControl.SCC** script library (`StationControl/SCC/code.py`) — all read/commit logic;
  every commit writes to `SupervisorOverrideLog` via the existing insert query.
- Three read-only FactoryControl named queries: `getActiveStations`,
  `getFabricationScheduleByComponent`, `getAssemblyScheduleBySerial`.
- Ignition import bundle `files/SCC_views_import.zip` (19 views) and rebuild tool
  `files/_rebuild_zip.py`.

### Notes
- No polling bindings anywhere; all data refreshes on demand.
- Concrete hex colors only (no theme tokens); no dark mode.
