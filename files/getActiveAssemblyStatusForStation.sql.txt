-- ============================================================================
-- THE ONLY NEW NAMED QUERY IN THE ENTIRE SCC BUILD.
-- Everything else reuses existing FactoryControl / FactoryGatewayEvents queries.
--
-- Why it's needed: every existing assembly-WIP query is serial-scoped
-- (GetWipStatus_BySerialNumberAndLine and CheckScheduledStatusBySerial both
-- require an exact :serialNumber). The Station ComponentID boundary check needs
-- the active count for a STATION regardless of serial, which no existing query
-- provides. This is a 4-line read, no writes.
--
-- Project: FactoryControl
-- Path:    Station Control Center/StationComponentID/select/getActiveAssemblyStatusForStation
-- Type:    Scalar Query (returns int)   Database: SCADA
-- Param:   stationName (String)
--
-- If you prefer to add NOTHING, skip this and the code fails safe (returns 0 active),
-- relying on the AMR-bound guard alone -- see README "Option B".
-- ============================================================================
SELECT COUNT(*)
FROM dbo.WIPWorkOrders_Assembly
WHERE StationName = :stationName
  AND Status = 2            -- 2 = WIP
  AND CompletedTimestamp IS NULL
