## KEY GOTCHAS / DECISIONS (don't re-break these)
- **scc-page tab children NEED `position.tabIndex`** (1st = {} =0, then 1,2,3). Without it all
  tabs bind to pane 0 → blank tabs. (Recurring miss — always set on rebuild.)
- **Table selection with single render:"view" `__card` column:** `selection.data` only carries
  VISIBLE columns → it's just `{__card}`. Derive selection from `props.selection.selectedRow`
  (index) + the table's `props.data` (full row), guarded by `selection.data` presence; filter
  disabled so the index stays aligned. (work-order/station/amr do this.)
- **WG (whole-good) serials in MachineConfig use description `'Product Code'`, NOT `ItemName`/
  `FinishedItemNumber`.** `checkSerialForAssembly` checks `['Product Code','ItemName']`.
- **Toast:** `modal=True` centers it (the real "not bottom-right" fix). NO `system.util.invokeLater`
  (errors in Perspective). Popup views import fine; the original "popups don't work" was just the
  toast view not being installed at `.../embedded/scc-toast-popup`. UPDATE (session 2): scc-toast-popup
  now supports a param-gated `autoClose` (default false) — manual-assembly toasts pass `autoClose=True` +
  `modal=False` + an explicit `position`, so they auto-dismiss ~2s and don't block; all other tabs still
  pass modal=True (centered, manual-dismiss). Auto-close = `custom.tick` expr `if(autoClose, now(2000), 0)`
  + an onChange that closes on the first real change (guard on `previousValue`, since Perspective change
  scripts have no `executeOnStartup` and fire on the initial eval).
- **Refresh after commit = OPTIMISTIC** (mutate the committed row in the custom-prop-backed data:
  amrRows / stationRows / scheduleRows). Re-reading was "too early" + extra load. Don't re-read.
- **deferUpdates=False** on text fields (default defers to blur → buttons only enabled after
  click-off). Keep False so buttons enable while typing.
- **Buttons:** icons via `props.image = {"icon":{"path":"material/<name>"}}` (NOT an `icon` prop);
  faded-when-disabled via inline color bindings (NOT style classes — couldn't import them).
- **Load discipline:** all query bindings `polling.enabled=false`; no timers/onChange/tag-change
  scripts; only fan-out reads = `getStationRows` (~256 tags) + `getAmrFleet`, each ONE batched
  read on tab/page open, no polling.
- Rules: concrete hex only (no theme tokens), `onSelectionChange` not `onRowClick`, tab-indented
  scripts, namespace `StationControl.SCC`, BE via `system.util.sendRequest(...executeFunction...)`.
